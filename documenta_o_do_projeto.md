# 🦖 JURASSIC ISLAND - Parque Científico e Reserva Biológica

Projeto Web completo e imersivo com tema de dinossauros e ficção científica. Inclui animações, sequenciador genético, terminal de segurança com alerta de emergência e mapa tático interativo.


## 🚀 Como Executar o Projeto no VS Code

Siga os passos simples abaixo para rodar o projeto localmente:

### 1. Baixar e Extrair o Arquivo ZIP
- Baixe o arquivo `.zip` contendo o projeto.
- Extraia o arquivo para uma pasta no seu computador (ex: `Área de Trabalho/jurassic-island`).

### 2. Abrir a Pasta no VS Code
1. Abra o **Visual Studio Code**.
2. No menu superior, clique em **File > Open Folder...** (ou `Arquivo > Abrir Pasta...`).
3. Selecione a pasta `jurassic-island` extraída.

### 3. Instalar a Extensão Live Server
1. Clique no ícone de **Extensões** na barra lateral esquerda do VS Code (ou pressione `Ctrl + Shift + X`).
2. Na barra de pesquisa, digite **Live Server**.
3. Localize a extensão criada por *Ritwick Dey* e clique no botão **Install**.

### 4. Rodar o Projeto com o Live Server
1. No painel esquerdo do VS Code (Explorador de Arquivos), clique com o botão direito sobre o arquivo **`index.html`**.
2. Clique na opção **"Open with Live Server"** (ou pressione `Alt + L, Alt + O`).
3. Seu navegador padrão abrirá automaticamente a aplicação no endereço `http://127.0.0.1:5500`.

## 🛠️ Recursos Incluídos no Site

- **Tela de Carregamento (Preloader)** com log do sistema.
- **Hero Section** cinematográfico com contadores estáticos do ecossistema.
- **Seção "A Ilha"** detalhando biomas e segurança.
- **Catálogo de Dinossauros** com filtros por tipo, estatísticas e Ficha Biológica em Modal com sintetizador de áudio.
- **Laboratório Genético** com simulação de fusão genômica e animação de fita de DNA em `<canvas>`.
- **Mapa Tático Interativo em SVG** com diagnósticos ao clicar em cada paddock/setor.
- **Terminal de Segurança estilo MS-DOS** com comandos clicáveis e modo de **Alerta Vermelho / Brecha de Segurança**.
- **Seção de Contato/Inscrição** para agendar expedições.
- **Botão Voltar ao Topo** e navegação mobile responsiva.
